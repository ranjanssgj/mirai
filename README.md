# Mirai

Mirai is a unified platform to **stream anime and read manga in one place**, built around the idea that anime and manga should not live in separate ecosystems.

Most anime fans never touch manga unless it gets popular enough to be adapted. Mirai is designed to bridge that gap by placing **anime seasons, episodes, and manga chapters side-by-side** for the same series, making discovery natural instead of forced.

> This project is currently in active development.

---

## Core Idea

Mirai pulls its primary database from **MyAnimeList (MAL)** and enriches each series with:

- Anime adaptations  
- Seasons and episode listings  
- Manga adaptations with chapter listings  

Instead of choosing between “anime apps” or “manga apps”, users can decide **per series** whether they want to:
- Watch the anime
- Read the manga
- Switch between both seamlessly

This encourages anime-only users to discover underrated or less-adapted manga organically.

---

## Features

### 📺 Anime Streaming
- Browse anime by season, adaptation, or series
- Episode-wise streaming
- Direct navigation from anime to its manga counterpart

### 📖 Manga Reading
- Chapter-wise manga reading
- Linked directly to anime adaptations
- Easy transition from anime → manga when adaptations end or diverge

### 🔁 Unified Series Pages
Each series page includes:
- Anime adaptations
- Seasons and episodes
- Manga adaptations and chapters
- Clear indicators of where anime ends and manga continues

### 📊 External Tracking Support
User activity can be tracked via third-party platforms such as:
- MyAnimeList (MAL)
- AniList
- Kitsu
- Other popular tracking services

No locked ecosystem — users keep their existing profiles.

### 💬 Community & Forum Integration
- Seamless forum integration for anime and manga a user follows
- Discussions tied directly to series, not scattered across platforms

---

## Why Mirai?

- Anime and manga are deeply connected, but platforms treat them separately
- Underrated manga often stays invisible to anime-only audiences
- Existing apps force users to pick a side

Mirai removes that split and lets the **story** decide the format.
